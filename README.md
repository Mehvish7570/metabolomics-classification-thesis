# Machine Learning for Classification on Untargeted Metabolomics Data
### A Comparative Study on IBD Subtype Classification

**MSc Health Data Science Thesis** — University of Birmingham (Dubai)
**Author**: Mehvish Shaikh
**Supervisor**: Dr. Imane Guellil, Cancer & Genomic Sciences, University of Birmingham

## Overview

This project investigates machine learning approaches for classifying inflammatory bowel disease (IBD) subtypes — Crohn's disease, ulcerative colitis, and non-IBD controls — from omics data. It builds on and compares five published methodologies (Acharjee/Hodgkiss, IBDpred, SIAMCAT, Vich Vila, MetAML), reproducing each on their own original dataset, then applying all five uniformly across three shared datasets for direct comparison. A new combined methodology, synthesised from lessons learned across this comparison, is then developed and evaluated against all five.

## Datasets

Three publicly available datasets were used throughout this project:

| Dataset | Type | Samples | Source |
|---|---|---|---|
| Franzosa (PRISM) | Untargeted metabolomics | 220 | Franzosa et al., 2019 |
| Jacobs | Untargeted metabolomics | 90 | Jacobs et al., 2016 |
| MetAML | Shotgun metagenomics | 445 | Pasolli et al., 2016 |
